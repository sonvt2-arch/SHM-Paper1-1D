# Reproducibility package

Code behind the revised manuscript

> **Deflection-integral invariance for indirect identification of total service loads on continuous beams: general theorem, error budget and experimental validation on a two-span bridge model**

Everything in the paper — every number, table, figure, equation image and the
`.docx` itself — is regenerated by these scripts. Nothing is hand-copied.

---

## Files

| File | What it does |
|---|---|
| `beam_theory.py` | **Shared module.** Specimen constants, the closed-form influence line (Eq. 6), the measured data of Tables 1 and 3, the BPM/SLM estimators, and a minimal Euler–Bernoulli beam FE solver. Every other script imports from here, so the constants live in exactly one place. |
| `01_verify_equations.py` | Independent symbolic (SymPy) + numeric verification of every equation. This is the script that found the errors listed in Annex A.1 of the paper. |
| `02_load_identification.py` | Tables 2, 4 and 5: deflection integrals, identified loads, quadrature convergence, calibration line, zero-offset sensitivity. |
| `03_monte_carlo.py` | Table 6: Monte Carlo with the three-component measurement model of Eq. (16), 200 000 realisations. |
| `04_parametric_study.py` | Section 4.5: Maxwell–Betti corollary check, span-ratio study (critical ratio 1.46), sensor-position study. |
| `05_make_figures.py` | All eleven figures at 600 dpi into `./figs/`. |
| `06_make_equations.py` | All display equations rendered by LaTeX into `./eqs/` as transparent PNGs. |
| `07_build_docx.js` | Assembles the manuscript with docx-js. |
| `docx_helpers.js` | Helper layer: inline mark-up parser, paragraph/heading builders, equation, figure and table constructors. |

## Requirements

```
python3  >= 3.10
    numpy, scipy, sympy, matplotlib, pillow
node     >= 18
    docx        (npm install docx)
LaTeX               pdflatex, with amsmath and mathptmx
Poppler             pdftoppm
```

Only `06_make_equations.py` needs LaTeX and Poppler. Scripts 01–04 need
nothing but the Python packages.

## How to run

Scripts 01–04 are independent and can be run in any order:

```bash
python3 01_verify_equations.py
python3 02_load_identification.py
python3 03_monte_carlo.py          # ~30 s
python3 04_parametric_study.py     # ~60 s
```

To rebuild the document, run the two asset generators first, then the builder:

```bash
python3 05_make_figures.py         # -> ./figs/
python3 06_make_equations.py       # -> ./eqs/
node     07_build_docx.js          # -> Revised_Manuscript_....docx
```

### One prerequisite for Figure 3

Panel (b) of Fig. 3 is the laboratory photograph, which lives inside the
original Word file. Extract it once:

```bash
unzip -o "01__Research_Paper_-_03.docx" -d dx
# the photograph is dx/word/media/image30.png
```

`05_make_figures.py` looks for it at that path (constant `PHOTO` at the top of
the file). If it is absent, the script prints a notice and renders panel (a)
only; everything else still works.

## What each script establishes

**`01_verify_equations.py`** confirms that Eqs. (1)–(6) and (11) of the paper
are correct, and demonstrates the three substantive errors in the earlier
draft:

- the factorised third branch of the mid-span deflection was printed with
  denominator `192EI` instead of `64EI` — the script prints the symbolic
  ratio `3` and the numeric consequence at *x* = 3750 mm (−1.1255 mm correct,
  −0.3752 mm as printed);
- the interior support cannot be rotation-restrained: the reactions in Eq. (1)
  give 13*P*/32 at *x* = *l*/2, which is the simple-support value;
- every force value was overstated by a factor of 1000.

**`02_load_identification.py`** shows that the BPM/SLM ratio is 1.00489 for
*both* load configurations and equals the ratio of the measured reference
integral to its exact value. That is common-mode cancellation observed
directly, and it is the empirical backbone of Section 4.1. The script also
prints the quadrature bias (−0.500 % for the trapezoidal rule at
Δ*x* = 250 mm, +0.027 % for Simpson) and shows that removing it would raise
the BPM deviation from +1.10 % to +1.61 % — two errors of opposite sign were
partly cancelling.

**`03_monte_carlo.py`** separates gain, offset and random noise. Random noise
of half the transducer resolution contributes 0.07 % standard deviation; the
systematic terms dominate by more than an order of magnitude. It also shows
that a single noisy reference crossing raises SLM scatter from 2.11 % to
3.09 %, contradicting the intuition that a ratio cancels noise. It does not:
for independent perturbations the relative variances add.

**`04_parametric_study.py`** verifies the Maxwell–Betti corollary numerically
(FE constant matches *l*⁴/192*EI* to eight significant figures), locates the
critical span ratio *l*₂/*l*₁ = 1.457 at which the invariance constant vanishes
and the method fails, and shows that the optimal sensor position is 0.42*l* —
only 4 % better than mid-span, so the choice made in the experiments was very
nearly optimal.

## Notes and caveats

- Units are **N and mm** throughout, so `EI` is in N·mm² and the deflection
  integral in mm². The gravitational conversion uses *g* = 9.81 m/s².
- The Monte Carlo seed is fixed (`SEED = 20260817` in `03_monte_carlo.py`), so
  results are reproducible to the last digit. Change it to check stability.
- `np.trapezoid` is the NumPy ≥ 2.0 spelling; on NumPy 1.x use `np.trapz`.
- The mark-up used inside the text of `07_build_docx.js` is deliberately
  minimal: `*italic*`, `**bold**`, `_subscript_`, `^superscript^`. It does not
  nest, so avoid `*a _b_ c*`.
- Table 1 of the paper has an empty last column (`[ ]`) for the standard
  deviation of the three repeated measurements. Those values are in the
  laboratory records and need to be filled in by hand in
  `07_build_docx.js` (array `t1rows`).
